# 无票例外审批流程

申请人应提交费用发生证明、支付凭证、无法取得票据的原因以及供应商信息。直属主管确认业务真实性后，由税务专员判断是否允许入账。

单笔超过 1000 元的无票费用还需财务负责人批准；同一申请人一个季度累计不得超过 3000 元。具体票据标准见[票据与税务合规要求](../policies/invoice-compliance-v1.md)。
