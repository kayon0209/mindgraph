# 图扩展消融（graph on / off）

数据版本 `2.4.0`，样本 90 例，策略 `hybrid`，top_k `5`，索引 `mg-20260903T041848Z-4f9cdf5b`，每例重复 `3` 次（延迟取中位数）。

## 结论

- 是否达到默认开启闸门：**否**
- 建议：`keep_graph_disabled`
- 未通过原因：recall_gain_below_threshold
- 局限性：无

## 指标对比

| 指标 | 图关闭（基线） | 图开启（实验组） | 差值 |
|---|---:|---:|---:|
| Recall@5（门控判据） | 0.8860 | 0.8860 | +0.0000 |
| MRR | 0.7851 | 0.7865 | +0.0014 |
| 完整证据集召回 | 0.8860 | 0.9035 | +0.0175 |
| 平均证据条数 | 4.91 | 6.41 | +1.5000 |
| 平均检索延迟 (ms) | 23.59 | 23.26 | 0.99x |

> **为什么要并列「完整证据集召回」与「平均证据条数」**：图扩展的机制是在
> Top-5 **之外**追加旁证，而 Recall@5 截断到 5 条——用它评判图扩展等于用
> 错的尺子量。实测（8 条 confirmed 关系、76 例）：R@5 增益 0.0000，但完整
> 证据集召回 +1.75pp、平均证据条数 4.91 → 6.41（+1.50 条），延迟还略降。
> 呈现这两个口径是为了看清「图扩展到底做了什么」，**不代表放宽晋升门槛**——
> 默认开启的判据仍是 Recall@5 ≥ +5pp 且延迟 ≤ 3×。
