# Assist UI 文案表（AGENT-UI-COPY-DECK）—— UI-G 闸门交付物

> 用户语言文案的唯一来源。界面禁止出现英文术语 Agent Plan / Tool Calls / token /
> reason code / 内部类名（AgentExecutionPolicy 等）。所有状态文案与
> AGENT-UI-STATE-MATRIX 的状态编号对应。

## 1. 执行步骤（PlanPanel / AgentExecutionSummary）

| 场景 | 文案 |
| --- | --- |
| 计划生成中 | 正在梳理问题，准备查询步骤… |
| 计划就绪（摘要行） | 已制定 {N} 个查询步骤 |
| 计划就绪（折叠标题） | 执行步骤 |
| 单步名称模板 | {step_label}（见步骤词典） |
| 步骤完成（摘要定格） | 已完成 {N} 步查询 |
| 某步跳过 | 此步不需要，已跳过 |
| 预算触顶降级 | 查询步骤过多，已回到单次检索 |

**步骤词典**（route→用户语言；禁止内部枚举名）：

| 内部 route（不外显） | 用户语言步骤名 |
| --- | --- |
| factual / exact_title | 直接查找制度原文 |
| structured_fallback + version_constraint | 定位指定版本 |
| exception_or_conflict | 排查例外与新旧差异 |
| cross_policy | 对比多份制度 |
| clarification_required | 先确认问题细节 |
| manual | 按你选择的检索方式 |

| 场景 | 文案 |
| --- | --- |
| 面板标题 | 执行记录 |
| 单条进行中 | 正在{目的}…（如：正在核对版本有效期） |
| 单条完成 | 已{目的}（{秒}s） |
| 单条失败 | {目的}未完成：{脱敏原因} |
| 单条超时 | {目的}超时，已停止这一步 |
| 单条无权限 | {目的}需要更高权限，已停止 |
| 汇总（部分失败） | 其中 1 步未完成 |

**工具目的词典**：

| 工具（不外显） | 用户语言目的 |
| --- | --- |

| mindgraph_get_policy_history | 核对版本有效期 |
| mindgraph_concept_gaps | 检查知识覆盖缺口 |
| mindgraph_verify_citations | 核对回答引用 |

## 3. 澄清卡（ClarificationCard）

| 场景 | 文案 |
| --- | --- |
| 卡片标题 | 为了准确回答，请补充 {N} 个信息 |
| 上下文说明 | 以上对话内容已保留，补充后将一起作为依据 |

| 过期 | 补充链接已过期（{分钟} 分钟内有效），请重新提问 |
| 已回答态 | 已补充 · {时间} |

## 4. 冲突卡（ConflictCard）

| 场景 | 文案 |
| --- | --- |
| 标题 | 检测到同一制度有多个同时生效的版本 |
| 说明 | 系统已停止生成答案。以下版本在查询日期均有效，需要制度责任人确认后才能回答。 |
| 版本行 | {版本} · 生效 {起} 至 {止} · {状态} · 责任人：{owner} |
| 操作 1 | 导出证据包 |
| 操作 2 | 联系制度责任人 |
| aria 播报 | 已停止生成：制度版本冲突，需要人工确认 |

## 5. 引用校验（CitationIntegrityNotice）

| 场景 | 文案 |
| --- | --- |
| 失败标题 | 回答未通过引用校验 |
| 失败说明 | 回答中的引用标注不完整，为避免误导，本次只提供证据原文 |
| 操作 1 | 重新组织引用（限一次） |
| 操作 2 | 只看证据原文 |
| aria 播报 | 本次回答未通过引用校验，已改为仅显示证据 |

## 6. 降级（LoopFallbackNotice / 横幅）

| 场景 | 文案 |
| --- | --- |
| 步骤降级 | 查询步骤过多，已回到单次检索；以下回答基于一次直接查找 |
| 检索降级（现有保留） | 本次回答质量已降低：{原因} |

## 7. 权限与空态（复用现有文案，M2 不改）

- 权限不足 → "你当前的账号权限看不到相关制度…请联系管理员开通对应工作区/部门。"（现有）
- 证据不足 → "检索到了问题，但未找到足够的制度证据…"（现有）
- 范围外 → "这个问题不在制度范围内，已停止回答。"（现有）
