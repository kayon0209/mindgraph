# 企业费用报销管理制度

## 第一章 总则

### 第一条 目的
为加强公司费用管理，规范费用报销流程，控制成本支出，提高资金使用效率，特制定本制度。

### 第二条 适用范围
本制度适用于公司全体员工因公产生的各类费用报销，包括但不限于：差旅费、业务招待费、办公费、通讯费、培训费等。

### 第三条 管理原则
1. **预算控制原则**：各项费用支出应在年度预算范围内，超预算支出须事先报批。
2. **分级审批原则**：根据费用金额和性质实行分级审批。
3. **合规合法原则**：费用报销须符合法律法规和公司规定。
4. **及时高效原则**：费用发生后应及时报销，审批流程应高效便捷。

---

## 第二章 费用分类与标准

### 第四条 费用分类
公司费用分为以下几类：
1. **差旅费**：因公出差产生的交通费、住宿费、伙食补助等
2. **业务招待费**：因业务需要招待客户产生的费用
3. **办公费**：日常办公用品、耗材、设备购置等
4. **通讯费**：电话费、网络费、邮寄费等
5. **培训费**：员工培训、会议、学习产生的费用
6. **其他费用**：不属于以上类别的其他合理费用

### 第五条 业务招待费标准

#### 5.1 招待标准
| 招待对象级别 | 人均标准 | 酒水标准 |
|-------------|----------|----------|
| 重要客户/高管 | 不超过500元 | 不超过300元 |
| 一般客户 | 不超过300元 | 不超过200元 |
| 内部员工 | 不超过150元 | 不超过100元 |

#### 5.2 招待规定
1. 业务招待应事先审批，填写《业务招待申请表》。
2. 单次招待费用超过2000元的，须事先经分管领导批准。
3. 招待费报销须提供发票和消费明细清单。
4. 严禁在高档娱乐场所进行业务招待。

### 第六条 办公费标准

#### 6.1 办公用品
1. 普通办公用品由行政部门统一采购，员工按需领用。
2. 单价超过500元的办公用品须事先申请。

#### 6.2 办公设备
1. 办公设备购置须纳入年度预算。
2. 单价超过2000元的设备须走固定资产采购流程。

### 第七条 通讯费标准

| 职级 | 月度通讯费限额 |
|------|---------------|
| 总经理/副总 | 500元 |
| 部门经理 | 300元 |
| 普通员工 | 150元 |
| 销售人员 | 300元 |

注：销售人员因业务需要可适当提高标准，但须说明理由。

### 第八条 培训费标准
1. 公司内部培训：由人力资源部统一安排，费用据实报销。
2. 外部培训：须事先审批，培训费用在年度培训预算内报销。
3. 培训费用包括：培训费、考试费、教材费、差旅费等。
4. 员工参加外部培训须签订培训协议，约定服务期。

## 第三章 报销流程

### 第九条 报销时限
1. 费用发生后应在**15个工作日内**办理报销手续。
2. 差旅费应在出差结束后**10个工作日内**报销。
3. 跨年度的费用原则上不得报销（特殊情况除外）。

### 第十条 报销凭证要求

#### 10.1 发票要求
1. 发票抬头须为公司全称：XX科技有限公司
2. 发票内容须与实际业务相符
3. 发票须加盖开票单位发票专用章
4. 发票须在有效期内（增值税专用发票须在360天内认证）
5. 电子发票须打印后报销，或按公司电子发票管理规定执行

#### 10.2 其他凭证
1. 差旅费：出差审批单、行程单、住宿清单等
2. 招待费：招待申请表、消费明细、招待对象信息等
3. 培训费：培训通知、培训协议、结业证书等

### 第十一条 报销审批权限

| 费用金额 | 审批人 |
|---------|--------|
| 500元以下 | 部门负责人 |
| 500-2000元 | 部门负责人 → 财务经理 |
| 2000-5000元 | 部门负责人 → 财务经理 → 分管领导 |
| 5000元以上 | 部门负责人 → 财务经理 → 分管领导 → 总经理 |

### 第十二条 报销流程
1. **填写报销单**：员工填写《费用报销单》，粘贴原始凭证
2. **部门审核**：部门负责人审核费用的真实性、合理性
3. **财务审核**：财务部门审核票据合规性、金额准确性
4. **领导审批**：按审批权限逐级审批
5. **出纳付款**：审批通过后，出纳办理付款

## 第四章 特殊费用规定

### 第十三条 预借款管理
1. 员工因公需要可预借备用金，须填写《借款单》。
2. 借款金额超过5000元的，须分管领导审批。
3. 借款应在业务结束后及时冲销，最长不超过3个月。
4. 前账未清，不得再次借款。

### 第十四条 加班费用
1. **加班餐费**：加班超过2小时的，可报销加班餐费，标准为每人每次不超过50元。
2. **加班交通费**：加班至晚上10点以后的，可报销打车费（需提供行程单）。
3. 加班须事先在考勤系统中申请，经部门负责人批准。

### 第十五条 团队建设费
1. 部门团建费用标准为每人每年不超过500元。
2. 团建活动须事先填写《团建活动申请表》。
3. 团建费用报销须提供活动方案、参与人员名单、费用明细。

### 第十六条 员工福利费
1. 节日福利：按公司统一标准发放，由人力资源部统一采购。
2. 生日福利：员工生日当月可报销不超过200元的生日蛋糕或礼品。
3. 健康体检：公司统一组织的体检，费用据实报销。

## 第五章 禁止行为

### 第十七条 禁止事项
1. 严禁虚报、冒领费用
2. 严禁将个人消费混入公务报销
3. 严禁开具虚假发票
4. 严禁拆分发票规避审批
5. 严禁接受供应商回扣或好处费
6. 严禁在报销中弄虚作假

### 第十八条 违规处理
对违反本制度的行为，视情节轻重给予以下处理：
1. **轻微违规**：违规费用不予报销，给予口头警告
2. **一般违规**：违规费用不予报销，给予书面警告，通报批评
3. **严重违规**：违规费用不予报销，扣减绩效奖金，调离岗位
4. **违法行为**：移交司法机关处理

## 常见问题解答（FAQ）

**Q1：发票抬头写错了可以报销吗？**
A：不可以。发票抬头必须为公司全称，写错的发票应退回重开。

**Q2：电子发票如何报销？**
A：电子发票须打印后粘贴报销，或按公司电子发票管理规定提交电子版。

**Q3：丢失了原始发票怎么办？**
A：应联系开票单位复印存根联并加盖公章，同时书面说明丢失原因。

**Q4：个人垫付大额费用如何报销？**
A：大额费用建议事先借款，避免个人垫付。如确需垫付，报销时可申请加急处理。

**Q5：招待客户时没有取得发票怎么办？**
A：原则上无发票不予报销。特殊情况须书面说明原因，经总经理批准后方可报销。

**Q6：出差期间的个人消费可以报销吗？**
A：不可以。只有因公产生的合理费用才能报销，个人消费应自行承担。

**Q7：报销被退回了怎么办？**
A：应根据财务部门的退回原因补充材料或更正后重新提交。

**Q8：跨年度发票可以报销吗？**
A：原则上不可以。特殊情况须书面说明原因，经总经理批准后方可报销。
