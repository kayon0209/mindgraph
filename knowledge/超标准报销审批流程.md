# 超标准报销审批流程

## 一、适用范围

以下情况属于超标准报销，须按本流程办理：

1. 住宿费用超过职级标准
2. 交通工具选择超过标准（如应坐经济舱却坐商务舱）
3. 餐饮费用超过标准
4. 其他费用超出制度规定标准

---

## 二、审批流程

### 2.1 事前审批（推荐）

如预计会超标准，应提前办理：

```
员工申请 → 部门负责人 → 分管领导 → 总经理（超5000元）
```

### 2.2 事后审批

已发生超标准消费，需补办：

| 超标准金额 | 审批层级 |
|-----------|---------|
| 500元以下 | 部门负责人 |
| 500-2000元 | 分管领导 |
| 2000-5000元 | 分管领导 + 财务负责人 |
| 5000元以上 | 总经理 |

---

## 三、所需材料

超标准报销除常规材料外，还需提供：

1. **超标准说明** - 书面说明超标准原因
2. **特殊情况证明** - 如会议通知、紧急任务证明等
3. **比价说明** - 说明当时选择的合理性
4. **审批单** - 按上述流程的审批签字

---

## 四、不予报销的情形

以下超标准费用不予报销：

- 无正当理由的超标准消费
- 未履行审批手续的超标准消费
- 与业务无关的个人消费
- 虚假理由的超标准报销

---

## 五、注意事项

1. 超标准报销应在出差结束后**10个工作日内**办理
2. 审批不通过的超标准部分由员工自行承担
3. 频繁超标准报销将影响个人绩效考核
